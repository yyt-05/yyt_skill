# Repository Instructions

## Keep the Skill index synchronized

Before creating or updating a pull request, compare the PR diff with the Skill catalog in `README.md`.

- When a Skill is added, add one row to the README table with its name, link, function, and applicable scenario.
- When a Skill is removed or renamed, update or remove its README row.
- When a Skill's purpose or trigger scope changes materially, update its function or scenario description in README.
- When the PR does not change the available Skills or their purpose, do not modify README only to create churn.
- Verify that every Skill link in README points to an existing `SKILL.md` before publishing the PR.
