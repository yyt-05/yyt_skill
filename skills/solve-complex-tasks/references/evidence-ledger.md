# 复杂任务证据账本

复杂任务进行中维护一份简洁账本，使判断和下一步不依赖聊天记忆。

## 任务契约

```markdown
## 决策或交付
<最终需要决定或交付什么>

## 受影响对象
<用户、系统、模块、负责人>

## 范围
- 包含：
- 不包含：

## 完成证据
- <可观察结果及验证方式>
```

## 事实边界

```markdown
| 项目 | 状态 | 证据 | 时间/版本/环境 | 对决策的影响 |
|---|---|---|---|---|
| ... | 已确认/未知/假设 | ... | ... | ... |
```

证据必须注明来源和适用边界。推断应明确标为推断。

## 假设表

```markdown
| 假设 | 支持证据 | 冲突证据 | 可证伪预测 | 验证方法 | 状态 |
|---|---|---|---|---|---|
| H1 | ... | ... | ... | ... | 保留/排除/已确认 |
```

## 实验记录

```markdown
## 实验名称
- 目的：
- 基线：
- 唯一变化变量：
- 固定条件：
- 成功/失败/停止条件：
- 实际命令或步骤：
- 结果与原始产物：
- 能支持的结论：
- 不能支持的结论：
```

## 决策记录

```markdown
## 当前决定
<选择什么>

## 为什么
- 关键证据：
- 被排除方案及原因：
- 仍未验证的假设：

## 风险与回滚
- 风险：
- 监测：
- 回滚条件和动作：

## 下一个最小动作
<最能减少剩余不确定性的动作、负责人和验收条件>
```
